# maZe — Personal Portfolio Website

A responsive personal portfolio website for **Kyle Benedict T. Ochavillo**, a BS Computer Science student from the University of Science and Technology of Southern Philippines — Cagayan de Oro.

The website showcases personal information, deployed systems, technical skills, certificates, development principles, contact information, and social media profiles.

The design uses a dark purple and deep-blue visual theme with smooth scrolling, scroll-based animations, interactive elements, and responsive layouts for desktop and mobile devices.
